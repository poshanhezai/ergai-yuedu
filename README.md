# 阅读egg版

> 根据个人喜好二改的阅读arc。

> 基于 [阅读 Archive](https://github.com/Rimchars/legado)（继承 [Legado](https://github.com/gedoor/legado)）的二次修改版本。
> 上游的阅读体验、书源规则引擎、主题、EPUB / 漫画 / 视频 / 朗读等能力完整保留，本仓库主要把**书源管理**做深做细。

## 相比上游的改动

### 书源分类

- **自动分类**：小说 / 漫画 / 成人 / 音频 / 视频 / 文件 / 其他，共七类。
- **导入即「未分类」**：不管导入的 JSON 里自带什么分组，一律丢弃，统一归到「未分类」。
- **检测之后才有真实分类**：跑过书源检测才会写入分类，分类存在书源上，导出书源时跟着走。
- **搜书只认这套分类**：搜书页顶部、换源对话框里的书源分类，只有未分类和检测后的七类，不再使用书源自带的分组。
- **重新分类**：不联网，按名称、地址、书源类型重新判定一次。

### 书源检测与清理

- **主动识别成人内容**：检测时真实请求一次书源搜索页，按页面特征词判断（强特征命中一条即判定，弱特征需命中两条），命中即归入「成人」。
- **批量检测**：沿用上游的校验书源（域名 / 搜索 / 发现 / 详情 / 目录 / 正文，可设并发数、超时、快速模式，可暂停继续停止），检测结果写回书源。
- **删除失效书源**：一键清理被标记为搜索失效 / 发现失效 / 域名失效 / 校验超时的书源。
- **书源去重**：地址（忽略 `#备注`）、名称、搜索 / 目录 / 正文规则都相同的判为重复，保留最早的一条。

### 按分类独立操作

- 分类筛选条常驻书源管理页顶部，显示每一类的数量。
- 每一类可以单独**筛选、导出、检测、整类删除、只删该类失效书源**。
- 想在某类里找书：选中分类后，搜索框会提示「在「漫画」中搜索书名/作者」，搜索只在该类书源中进行。
