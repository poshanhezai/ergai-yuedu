# 对话与角色行为段落规则

本规则按照示例截图的效果设计：**只改变对话和紧跟在对话后的角色行为或角色名，普通旁白及其他正文保持原样**。

规则文件：`dialogue-highlight-paragraph-rule.json`（普通正文保持原样版）

## 十四条说明

### 1. 规则主要能力

- 引号内内容识别为对话，并使用对话颜色。
- 对话结束后的第一个连续行为句或角色名使用行为颜色；该行为句结束后的普通旁白保持原样。
- 没有完整引号的段落不处理，普通旁白、环境描写和其他正文不改变颜色。
- 支持中文弯引号、直角引号、双层引号以及英文单双引号。
- 对 emoji 和部分特殊字符做安全处理，减少 HTML 解析导致的乱码。

### 2. 导入和启用方法

1. 下载 `dialogue-highlight-paragraph-rule.json`。
2. 在阅读egg版进入段落规则管理，选择导入。
3. 启用规则，重新打开或刷新正文。
4. 使用同时包含对话、角色行为和普通旁白的章节进行测试。

### 3. 默认识别效果

- 对话默认颜色：`#9D5960`，接近截图中的紫灰色。
- 角色行为或角色名默认颜色：`#334E52`，接近截图中的深青色。
- 普通旁白以及没有对话的正文：保持原来的颜色和显示方式。
- 默认不启用背景色、粗体、斜体、下划线、删除线和字号变化。

### 4. 修改样式的方法

在规则变量中修改 `dialogColor`、`actionColor` 等变量。建议使用段落规则管理界面的变量编辑功能修改，不要随意改动脚本逻辑。

### 5. 所有可用变量

| 变量 | 用途 |
| --- | --- |
| `dialogColor` | 对话文字颜色 |
| `actionColor` | 角色行为或角色名颜色 |
| `dialogBackground` | 对话背景色，留空关闭 |
| `actionBackground` | 行为背景色，留空关闭 |
| `dialogBold` / `dialogItalic` | 对话粗体 / 斜体 |
| `dialogUnderline` / `dialogStrike` | 对话下划线 / 删除线 |
| `dialogSize` | 对话字号：`small`、`big`、`large`、`x-large` |
| `actionBold` / `actionItalic` | 行为粗体 / 斜体 |
| `actionUnderline` / `actionStrike` | 行为下划线 / 删除线 |
| `actionSize` | 行为字号 |

### 6. 颜色格式注意事项

所有颜色必须使用六位十六进制格式 `#RRGGBB`，例如 `#9D5960`、`#334E52`、`#FFF2CC`。

不支持 `red`、`#FFF`、`#FFFFFF80` 或不带 `#` 的格式。填写错误时会回退到默认颜色；背景颜色填写错误时保持关闭。

### 7. 背景颜色说明

背景色默认关闭。需要使用时填写浅色六位颜色，例如：

```text
dialogBackground = #FFF2CC
actionBackground = #EAF4F4
```

背景只作用于识别出的对话或角色行为片段，不会改变整页背景。

### 8. 文字样式设置

对话和角色行为可以分别设置粗体、斜体、下划线和删除线，值填写 `true` 或 `false`。建议一次只开启一种样式，便于判断最终效果。

### 9. 字号设置

`small` 表示较小，`big` 或 `large` 表示较大，`x-large` 表示更大；留空或 `normal` 使用阅读器默认字号。规则不能导入或替换 `.ttf` / `.otf` 字体文件。

### 10. 多层引号处理方式

规则只把完整的最外层引号范围作为对话：

- `“他说“甲”，又说“乙”。”` 整体作为一段对话；
- `「外层『内层』结束」` 整体作为一段对话；
- 多个独立对话会分别识别；
- `don't`、`I'm` 中的英文撇号不会误判为引号。

### 11. 特殊符号处理

emoji 和部分四字节字符会转换为 HTML 数字实体，以减少显示为 `�` 的情况。若源文件本身已经是乱码，规则不能恢复原文；emoji 能否显示还取决于系统字体。

### 12. 支持的书籍格式

规则处理的是阅读器传入的普通正文段落，通常适用于 TXT 和部分在线正文。只要对应格式最终交给阅读器的段落规则处理，就可以生效；EPUB、PDF、漫画、音频、视频等可能使用独立渲染流程，不能保证经过段落规则。

### 13. 当前规则限制

- 规则不能真正理解语义，只能依据完整引号和文本位置判断；对话后的第一个句号、问号或感叹号之前的连续片段会按角色行为处理。
- **引号前的正文不染色**；只有对话后的第一个连续行为句或角色名才作为角色行为处理；后续普通正文不染色。
- 没有完整闭合引号的段落保持原样，避免误染整段正文。
- 规则不修改原书文件，也不负责书源、网络和章节内容修复。

### 14. 推荐配置

建议先保持默认配置：

```text
dialogColor = #9D5960
actionColor = #334E52
dialogBackground =
actionBackground =
dialogBold = false
actionBold = false
```

如果想接近截图，只设置对话和角色行为的文字颜色，不开启背景色；这样普通旁白会保持默认黑色。

## 效果示例

输入：

```text
“爸爸，你慢点喝，还有。”唐三接过父亲手中的碗，再给他盛了一碗粥。
在唐门的时候，他就从来没有离开过那里。
```

处理结果：

- `“爸爸，你慢点喝，还有。”`：对话颜色；
- `唐三接过父亲手中的碗，再给他盛了一碗粥。`：角色行为颜色；
- `在唐门的时候……`：完全保持原正文颜色。

## 安全边界

本规则只处理正文显示，不会联网、不会上传数据、不会改写书籍文件，也不会改变阅读器的其他功能。
