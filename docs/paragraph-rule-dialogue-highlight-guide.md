# 对话高亮自定义段落规则

本目录提供一个可导入阅读egg版的段落规则，用于把正文中的对话、叙述文字和百分比内容分别设置颜色、背景色与文字样式。

规则文件：[dialogue-highlight-custom-style-fixed.json](../paragraph-rules/dialogue-highlight-custom-style-fixed.json)

## 十四条说明

### 1. 规则主要能力

- 自动识别中文直角引号、弯引号、单双层引号，以及英文单双引号包围的对话。
- 对话、普通叙述文字、百分比内容分别设置文字颜色和可选背景色。
- 对话、叙述、百分比三类内容可以分别设置粗体、斜体、下划线、删除线和字号。
- 通过 HTML 数字实体保留常见四字节符号和 emoji，减少被正文 HTML 解析器替换成乱码的情况。
- 颜色输入严格按六位十六进制格式校验。

### 2. 导入和启用方法

1. 将 `dialogue-highlight-custom-style-fixed.json` 下载到手机。
2. 打开阅读egg版，进入段落规则管理界面。
3. 选择“导入”或从文件导入，选中该 JSON 文件。
4. 启用规则，并将它放到需要生效的段落规则顺序中。
5. 打开或重新加载正文，确认对话、叙述和百分比样式已经生效。

如果导入后没有变化，请先确认规则已启用，并确认当前阅读内容确实经过段落规则处理；必要时重新打开章节。

### 3. 默认识别效果

默认情况下：

- 引号包围的内容使用对话颜色 `#9D5960`。
- 未被引号包围的内容使用叙述颜色 `#274B5A`。
- 数字百分比（例如 `50%`、`12.5%`）使用百分比颜色 `#4F6FAE`。
- 三类背景色默认关闭，不会给正文增加背景色。
- 默认不强制加粗、斜体、下划线、删除线或改变字号。

### 4. 修改样式的方法

在规则 JSON 的 `script` 开头，使用 `vars` 中的变量修改样式。变量名区分大小写，值建议写成字符串。例如：

```javascript
vars.dialogColor = "#C0392B";
vars.dialogBackground = "#FFF2CC";
vars.dialogBold = "true";
```

如果阅读egg版的段落规则界面支持变量配置，应优先在界面中填写同名变量；没有填写的项目会使用规则内置默认值。

### 5. 所有可用变量

| 变量 | 用途 |
| --- | --- |
| `dialogColor` | 对话文字颜色 |
| `dialogBackground` | 对话背景颜色，留空关闭 |
| `dialogBold` / `dialogItalic` | 对话粗体 / 斜体 |
| `dialogUnderline` / `dialogStrike` | 对话下划线 / 删除线 |
| `dialogSize` | 对话字号：`small`、`big`、`large`、`x-large`，也支持 `小`、`大`、`超大` |
| `narrationColor` | 叙述文字颜色 |
| `narrationBackground` | 叙述背景颜色，留空关闭 |
| `narrationBold` / `narrationItalic` | 叙述粗体 / 斜体 |
| `narrationUnderline` / `narrationStrike` | 叙述下划线 / 删除线 |
| `narrationSize` | 叙述字号 |
| `percentColor` | 百分比文字颜色 |
| `percentBackground` | 百分比背景颜色，留空关闭 |
| `percentBold` / `percentItalic` | 百分比粗体 / 斜体 |
| `percentUnderline` / `percentStrike` | 百分比下划线 / 删除线 |
| `percentSize` | 百分比字号 |

布尔变量接受：`true`、`1`、`yes`、`on`、`是`；其他值视为关闭。

### 6. 颜色格式注意事项

颜色必须使用**六位十六进制格式**：`#RRGGBB`。例如：

- 红色：`#E53935`
- 橙色：`#F57C00`
- 黄色：`#FBC02D`
- 绿色：`#43A047`
- 青色：`#00ACC1`
- 蓝色：`#1E88E5`
- 紫色：`#8E44AD`
- 粉色：`#D81B60`
- 深灰：`#37474F`

不要填写 `red`、`#FFF`、`#FFFFFF80` 或不带 `#` 的颜色值。格式不正确时，规则会回退到默认颜色；背景色格式不正确时会保持关闭。

### 7. 背景颜色说明

背景变量留空字符串表示关闭，例如：

```javascript
vars.dialogBackground = "";
```

建议背景色使用浅色，避免降低正文可读性，例如对话使用 `#FFF2CC`，叙述使用 `#EAF4F4`，百分比使用 `#E8F0FE`。背景色是按对应内容片段包裹的，不是整页背景。

### 8. 文字样式设置

粗体、斜体、下划线和删除线分别独立控制，可以组合使用。例如：

```javascript
vars.dialogBold = "true";
vars.dialogItalic = "true";
vars.dialogUnderline = "false";
vars.dialogStrike = "false";
```

规则只负责生成对应的正文 HTML 样式，最终显示效果还会受到阅读器主题、字体和 HTML 解析能力影响。

### 9. 字号设置

字号变量支持：

- `small` 或 `小`：较小字号；
- `big`、`large` 或 `大`：较大字号；
- `x-large`、`xlarge` 或 `超大`：更大字号；
- 留空或其他值：使用阅读器默认字号。

规则不直接写入 `.ttf` / `.otf` 字体文件，也不能替换系统字体。这里只控制字号，不是字体文件导入功能。

### 10. 多层引号处理方式

规则采用栈识别完整的最外层引号范围：

- `“他说“甲”，又说“乙”。”` 会把最外层整段作为对话处理；
- `「外层『内层』结束」` 会把外层整段作为对话处理；
- 一句话中存在多个独立引号时，每个完整引号范围分别处理；
- 英文双引号和单引号会正常闭合；
- 英文单词中的撇号，如 `don't`、`I'm`，不会被当成对话引号。

如果引号只有开始没有结束，规则不会把未闭合部分强制判定为对话。

### 11. 特殊符号处理

规则会把成对 UTF-16 代理项（常见于 emoji 和部分四字节符号）转换为 HTML 数字实体，并对正文中的 `&`、`<`、`>`、单双引号进行转义，以减少 HTML 拼接造成的乱码或结构破坏。

这不能修复源文件已经发生的编码损坏。如果原文在进入规则前就已经显示为 `�`、问号或其他错误字符，规则无法还原原始字符。emoji 能否显示还取决于手机系统和当前字体是否包含该字形。

### 12. 支持的书籍格式

规则本身处理的是阅读器传入的“段落正文”，因此通常可用于 TXT 以及能被阅读egg版转换为普通正文段落的部分文本来源和在线正文。

EPUB、PDF、漫画、音频、视频等内容可能使用独立的渲染流程，不能保证经过段落规则。是否生效以当前版本阅读器的实际处理链为准。

### 13. 当前规则限制

- 只处理段落规则引擎收到的正文段落，不修改原书文件。
- 不负责登录、网络请求、书源解析或章节内容修复。
- 不保证所有网站的特殊 HTML、脚本、图片、分页标记都能参与高亮；受保护内容会跳过再次包裹。
- 复杂或不成对的引号可能无法识别，这是为了避免误把大段正文染成对话。
- 颜色仅支持 `#RRGGBB` 六位格式；不支持透明度八位写法。
- 样式标签的最终效果依赖阅读器的 HTML 支持和主题设置。

### 14. 推荐配置

推荐先使用低饱和、浅背景配置，确认可读性后再逐项调整：

```javascript
vars.dialogColor = "#9D5960";
vars.dialogBackground = "#FFF2CC";
vars.narrationColor = "#274B5A";
vars.narrationBackground = "";
vars.percentColor = "#4F6FAE";
vars.percentBackground = "#E8F0FE";
vars.dialogBold = "true";
vars.dialogItalic = "false";
vars.narrationBold = "false";
vars.percentBold = "true";
```

第一次测试建议只开启对话背景色；确认效果正常后，再开启叙述/百分比背景、字号或其他文字样式，便于定位显示问题。

## 兼容性与安全边界

本次发布只增加段落规则 JSON 和说明文档，不包含 APK，不修改阅读egg版现有源码、书源、导航或其他阅读功能。规则不会自动联网，也不会上传或改写用户的书籍内容。
